# Minkara Freed Archive

Офлайн-архив страниц сайта [minkara.carview.co.jp](https://minkara.carview.co.jp)
по **всем моделям Honda Freed** (все поколения и годы): заметки по ремонту и
DIY (整備手帳), обзоры запчастей, отзывы владельцев. Тексты переводятся на
русский, результат собирается в локальный статический сайт с поиском.

## Зачем

Сайт отдаёт `403 Forbidden` для российских IP (geo-блок на edge-узлах
Yahoo! JAPAN). Заголовки (`Accept-Language` и пр.) больше не помогают —
нужен выход за пределы РФ. Архив позволяет:

* хранить нужные страницы локально и смотреть их без сети и без VPN;
* искать по всем заметкам сразу (включая русский перевод);
* не зависеть от доступности сайта в будущем.

работы (скачанные страницы, картинки, SQLite, собранный сайт, черновики),
лежит в `data/`, `out/`, `work/` и игнорируется git.

## Установка

```bash
bash scripts/setup.sh
```

Скрипт поставит `uv`, создаст `.venv`, установит зависимости и инструменты
(`ruff`, `pytest`, `sqlite-utils`), настроит MCP и проверит доступ к сайту.
Рут не нужен.

Вручную (без `uv`):

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config/settings.example.env config/settings.local.env
```

## Быстрый старт

```bash
# 1. Собрать список URL по всем моделям со словом Freed
#    (листинги + профили машин; поколение — только метаданные)
python3 scripts/01_discover.py --brand honda --match freed

# 2. Скачать страницы и картинки (можно прерывать и запускать снова)
python3 scripts/02_fetch.py --limit 50

# 3. Перевести тексты (по умолчанию — провайдер echo, без сети)
python3 scripts/03_translate.py --limit 20

# 4. Собрать офлайн-сайт
python3 scripts/04_build.py

# 5. Посмотреть: открыть out/site/index.html в браузере
#    (Linux — view.sh, macOS — view.command, Windows — view.bat)
```

Каждый этап идемпотентен: повторный запуск продолжает с того места, где
остановились, и не перекачивает уже готовое.

## Просмотр

Результат — **статический сайт**: открывается двойным кликом в любом браузере
на Linux, Windows и macOS, без установки софта и без локального сервера.
Поиск работает офлайн (индекс в `search-index.js`, поэтому `file://` не
мешает).

Опционально: `python3 scripts/serve.py` — локальный сервер на stdlib, если
хочется «как настоящий сайт» с нормальными URL.

## Другие марки

Марки и модели описаны в `config/models.yaml`, правила поколений — в
`config/generations.yaml`. Добавление марки не требует правки кода: достаточно
дописать блок в YAML и запустить `01_discover.py --brand <марка>`.
Подробности — в `docs/plan.md`.

## Требования к сети

Все запросы идут с вашего IP. Если вы в РФ, перед запуском нужен VPN/прокси
с выходом за пределы РФ (Япония не обязательна). Проверка:

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://minkara.carview.co.jp/
# 200 — можно работать, 403 — включите VPN
```

Скрипты соблюдают `Crawl-delay: 1` из robots.txt и по умолчанию ходят не
чаще одного запроса в секунду (`MINKARA_DELAY`). Это не только вежливость:
при агрессивном темпе edge начинает отдавать 403.
