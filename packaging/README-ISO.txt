# Minkara Freed Archive — офлайн-архив

Это статический сайт. Ничего устанавливать не нужно — нужен только браузер.

## Linux

```bash
sudo mount -o loop minkara-archive.iso /mnt
xdg-open /mnt/index.html
# отмонтировать: sudo umount /mnt
```

Или запустите `view.sh` из смонтированного образа.

## macOS

Дважды кликните ISO — он смонтируется как диск. Откройте `index.html`
или запустите `view.command` (если система блокирует — правый клик →
«Открыть»).

## Windows 10/11

Правый клик по ISO → «Подключить». Откройте `index.html` или запустите
`view.bat`.

## Что внутри

- `index.html` — таблица материалов с поиском и фильтрами;
- `notes/` — заметки;
- `models/` — страницы моделей;
- `authors/`, `cars/` — материалы авторов и машин;
- `media/` — изображения;
- `open.html` — открытие сохранённой страницы по оригинальному адресу minkara.

## Если браузер ограничивает file://

Некоторые браузеры ограничивают iframe/печать для локальных файлов.
Тогда запустите любой статический сервер в смонтированном каталоге, например:

```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/
```

Контент и переводы принадлежат авторам и Carview; архив предназначен
для личного некоммерческого использования.
